# Themes and templates

fastr-docs separates the documentation system from its visual identity. Every template uses the same `docs.Router`, route tree, search index, PWA export, OpenAPI plugin, blog, and accessibility behavior. Choose a starting point at build time, then tune GoFastr's semantic tokens for your product.

## Five starting points

- **Editorial** — warm, compact, and focused on a clear reading rhythm. This is the default.
- **Terminal** — monospace, high-contrast, and command-line inspired.
- **Blueprint** — cool-toned, technical, and structured around a grid.
- **Studio** — expressive, softly rounded, and suited to product documentation.
- **Notebook** — paper-toned, reading-first, and led by serif typography.

Each template includes light and dark values. The user's preferred color scheme and the native GoFastr theme toggle continue to work after a template is selected.

## Choose a template

Pass the template to the same router that owns your pages:

```go
router := docs.NewRouter(
    docs.WithTemplate(docs.TemplateBlueprint),
)
```

The generated starter also reads `DOCS_TEMPLATE`, so you can preview a different starting point without editing the route tree:

```text
DOCS_TEMPLATE=notebook go run .
```

Unknown values fall back to `editorial`.

## Customize semantic tokens

Use `WithTheme` when the preset is close but your brand needs different colors, fonts, or shape:

```go
router := docs.NewRouter(
    docs.WithTheme(docs.ThemeConfig{
        Template: docs.TemplateStudio,
        Overrides: docs.ThemeOverrides{
            Primary:     "#8B5CF6",
            Accent:      "#F97316",
            FontHeading: "Manrope, Inter, sans-serif",
            RadiusMd:    12,
            DarkColors: map[string]string{
                "primary": "#C4B5FD",
                "accent":  "#FDBA74",
            },
        },
    }),
)
```

`ThemeOverrides` is GoFastr's semantic token set. It covers the page surfaces, text, borders, status colors, code blocks, font families, and shared radii. Empty fields keep the selected template value. Use `DarkColors` for contrast-safe dark-mode values instead of assuming a light color can be reused.

## Wire the theme into the host

Give the same router theme to the GoFastr app. This keeps framework components and the fastr-docs shell on one token system:

```go
site := uiapp.NewApp("Acme Docs").
    WithTheme(router.Theme()).
    WithLang(router.Language())
```

The starter generated by `fastr-docs init` already does this. Custom hosts can append trusted project CSS through `ThemeConfig.CustomCSS`; use it for project-owned components or a small layout adjustment, while keeping the core shell on semantic tokens.

## Keep the route model stable

Templates are not alternate content trees. A link to `/docs/getting-started` remains the same link in every template, and plugins such as OpenAPI continue to mount into the same router. That means changing the visual starting point does not invalidate bookmarks, search results, RSS, or offline content.
